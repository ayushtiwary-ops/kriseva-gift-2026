# KRISEVA ATTEST

The accountability layer for AI-assisted regulatory reporting in GIFT City.

## The problem

A GIFT City fund's quarterly return often has one number backed by several documents, and they disagree. AI tools read fast and pick an answer silently, with no record of which document they trusted or why. IFSCA took 19 enforcement actions in the first half of 2026 alone; when a regulator asks who decided, silence is not a defensible answer.

## The solution

KRISEVA ATTEST reads every source document and pins each proposed value to its exact origin. When sources conflict, or nothing supports a field, the model abstains instead of guessing, and a named human decides with a recorded reason. A second named human confirms the decision, and the system seals the case into a hash chain that breaks visibly if anyone tampers with it afterward.

## The spine

PROPOSE -> ABSTAIN -> DECIDE -> CONFIRM -> SEAL

1. PROPOSE: the model pins a value to its exact source, or finds none.
2. ABSTAIN: on conflict or missing evidence, it refuses to guess.
3. DECIDE: a named human chooses, with a reason on record.
4. CONFIRM: a second named human signs; the decider cannot self-approve.
5. SEAL: every artifact hash-chains together; tampering breaks it visibly.
